# 翻訳スタイルガイド

[ja.xml](ja.xml) を修正・追加するときの決まりです。訳語の一覧は [用語集](GLOSSARY.md) を参照してください。

Bio Inc. Redemption は、医師として患者を治す「ライフ」と、病気を操って犠牲者を死に至らせる「デス」の
どちらかの側で遊ぶ医療シミュレーションです。ブラックユーモアのあるゲームなので、原文の皮肉や軽口の調子は日本語でも保ちます。

## 1. ファイルの形式

ゲーム本体の言語ファイルと同じ形式です。`name` がゲーム内部のキー、要素の中身が訳文です。

```xml
<string name="Button.Close">閉じる</string>
<string name="Homescreen.Menu.ChooseLife">&lt;b&gt;ライフ&lt;/b&gt;を選ぶ</string>
```

- 文字コードは UTF-8、キーは1つにつき1行です。キーの名前は変更しないでください。
- 訳文の中の `<` `>` `&` は、XML の決まりに従って `&lt;` `&gt;` `&amp;` と書きます。
- 訳が空の行や、ファイルに無いキーは「未翻訳」として扱われ、ゲームの元の言語で表示されます。
- キーは文脈の手掛かりになります(例: `Tutorial.Kill.*` はデス側のチュートリアル、`*.Title` は見出し、`*Button*` はボタン)。

## 2. そのまま残すもの

次の記号は、ゲームが実行時に別の文字列へ置き換えたり、書式として解釈したりします。
**原文と同じ種類を、同じ数だけ**残してください。語順に合わせて位置を動かすのは構いません。

| 記号 | 例 | 意味 |
|---|---|---|
| 書式指定子 | `{0}` `{1}` `{2}` | 患者の名前、病名、数値などが入る。原文に無い番号を足すと、ゲーム内でエラーになる |
| リッチテキストタグ | `<b>` `</b>` `<color=#ff0000>` `</color>` `<size=20>` `<br>` | 太字・色・大きさ・改行。強調されていた語に相当する日本語を囲む |
| 角括弧の記号 | `[arg]` `[arg2]` `[1]` `[key:Chat]` | 数値やキー名に置き換わる |
| 文字としての `\n` | `1行目\n2行目` | 改行(バックスラッシュと n の2文字) |

そのほかの注意点です。

- `{` と `}` は書式指定子以外に使わないでください(書式エラーになります)。
- 原文に閉じタグが無い場合(`<color=...>` だけで `</color>` が無いなど)は、訳文も原文に合わせます。
- 次の固有名詞は訳さず、そのまま書きます: Bio Inc. Redemption、Bio Inc.、DryGin Studios、Steam、Discord、
  他のゲームの題名、URL、メールアドレス。

## 3. 文体

- **説明文・チュートリアル・ツールチップ・ダイアログの本文**は「です・ます調」にし、文末に「。」を付けます。
- **ボタン・ラベル・見出し・項目名**は、簡潔な体言止めや動詞の言い切りにし、文末に「。」を付けません。
- 原文がすべて大文字でも、日本語は普通に書きます。
- 「あなた」「彼」「彼女」などの代名詞は、無くても通じるなら省きます(患者は男女どちらもあり得ます)。
- 病気の解説は、原文が読者へ語りかける形でも、日本語では「〜する病気です」のような一般的な説明文にします。
- 医学用語は、日本で標準的に使われる用語を使います。「がん」はひらがなで書きます。
- `{0}` には患者(犠牲者)の名前や病名などが入ります。自然な助詞を付けます(例: 「{0}は狭心症を発症しました。」)。

## 4. 表記

- 数字・英字・`%` `+` `-` `/` は半角にします。
- 日本語の文中の句読点・感嘆符・疑問符・コロン・括弧は全角にします(、。！？：（）)。
  ただし `{0}%` や `+{0}` のように数値に付く記号は半角のままにします。
- 三点リーダーは「…」を使います。
- 器官系の名前(循環器系など)は、訳語に「系」まで含みます。原文で名前の後ろに system が続く文では、
  書式指定子だけを書きます(例: 「{0}の健康度が{1}未満である必要があります。」)。

## 5. 訳し分けに注意する語

| 原文の語 | 訳し方 |
|---|---|
| evolve(バイオマップの項目をポイントで手に入れる) | **取得する**。ボタンの表示は「取得」、手に入れた後は「取得済み」 |
| evolve(デス側で、犠牲者に新しい病気を起こす) | **発症させる**(例: 「4個の病気を発症させる」) |
| evolve(病気が上位の病気へ変わる) | **進化させる**(例: 「インフルエンザをH1N1に進化させます」) |
| Booster(ステージ前に選ぶ強化) | **スキル**(ゲーム内の英語表示も Skill に置き換えられている) |
| Click / Tap | **クリック**(PC版のため) |
| terminate(器官系に対して) | **機能停止させる** |
| terminate / kill(犠牲者に対して) | **死亡させる** |
| patient / victim | ライフ側は**患者**、デス側は**犠牲者** |

## 6. 長さ

- 訳文は簡潔にまとめ、原文より長くならないようにします。日本語の文字数は、英語の文字数の6割程度が目安です。
- ボタンやラベルは特に短くします。長い語は枠の中で折り返されて読みにくくなります
  (例: ランキング欄の「該当なし」は折り返してしまうため「N/A」としています)。

## 7. 同じ画面のボタンは別の訳にする

ゲームは、ダイアログで押されたボタンを**表示されている文字列**で判別している箇所があります。
「はい/いいえ」「承諾/拒否」「設定に戻る/初期設定に戻す」のように同じ画面に並ぶボタンを同じ訳にすると、
押したボタンを取り違えます。必ず互いに異なる訳にしてください。

## 8. 確認の方法

1. ゲームで確認します。ゲームフォルダの `BepInEx\plugins\BioIncRedemptionJP\ja.xml` を書き換えると、
   次回の起動時に反映されます。ゲーム中は次のキーが使えます。

   | キー | 動作 |
   |---|---|
   | `Ctrl + F10` | 翻訳ファイルを読み込み直す |
   | `Ctrl + F9` | 各文言の前にキーを表示する(もう一度押すと元に戻る) |

   開いたままの画面には、再読み込みした内容がすぐには反映されないことがあります。画面を開き直してください。

2. ゲームフォルダの `BepInEx\LogOutput.log` を開き、`BioIncRedemptionJP` の行を確認します。
   翻訳ファイルが読み込めなかったときや、書式指定子・タグなどが原文と合わない訳があったときは、ここにエラーや警告が出ます。
   原文と合わない訳は使われず、その文言は原文のまま表示されます(警告に、該当するキーが表示されます)。
