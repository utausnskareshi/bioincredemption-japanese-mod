# Bio Inc. Redemption 日本語化パッチ(非公式)

Steam 版 **Bio Inc. Redemption** の画面表示を日本語にする、非公式のファン制作パッチです。

- ボタン1つで日本語化でき、同じボタンでいつでも元に戻せます。
- ゲーム本体のファイルは書き換えません(ファイルを追加するだけです)。
- ゲーム内の設定画面に「日本語」ボタンが増え、他の言語へも切り替えられます。

> **ご注意**
> このパッチは DryGin Studios の公式のものではありません。利用は自己責任でお願いします。
> 本パッチについて、ゲームの開発元へ問い合わせないでください。

## 動作環境

- Windows 10 / 11(64bit)
- Steam 版 Bio Inc. Redemption(動作確認: ビルド 25931977 / ゲーム内表示 Version 1.20.0)
- 追加のランタイムなどのインストールは不要です(必要なものは同梱しています)。

## 使い方

1. [Releases](https://github.com/utausnskareshi/bioincredemption-japanese-mod/releases) から最新の配布ZIPをダウンロードし、**すべて展開**します(ZIP の中から直接実行しないでください)。
2. ゲームが起動している場合は終了します。
3. `BioIncRedemptionJP.exe` を実行します。
   - ゲームがインストールされていない場合は、その旨を表示して終了します。
4. **「日本語化する」** を押します。
5. Steam からゲームを起動すると、日本語で表示されます。

### 元に戻す

もう一度 `BioIncRedemptionJP.exe` を実行し、**「元に戻す」** を押します。
追加したファイルをすべて取り除き、ゲームフォルダを日本語化前の状態へ戻します。

### 初回実行時の警告について

このツールにはコード署名が無いため、初回実行時に「Windows によって PC が保護されました」と表示されることがあります。
「詳細情報」→「実行」で起動できます。ZIP が改ざんされていないかは、同時に配布している `.sha256` の値と
ZIP の SHA-256 を比べて確認できます。

```powershell
Get-FileHash .\BioIncRedemptionJP-v1.0.0.zip -Algorithm SHA256
```

## ゲーム内での言語の切り替え

ゲームの「オプション」画面の言語一覧に **「日本語」** が追加されます。

- 「日本語」を選ぶと日本語表示になります。
- 英語など他の言語を選ぶと、その言語の表示になります(パッチを外す必要はありません)。
- ゲーム標準の言語と同じく、切り替えは**ゲームの再起動後**に反映されます。

## 日本語化される範囲

- メニュー、チュートリアル、ステージ中の表示、病気・症状・検査・治療の名称と説明など、ゲームが文言として持っているテキスト(約2,000件)。
- 日付の表記(例: `2026年11月10日`)。

次のものは日本語化されません。

- 画像や動画に描き込まれた文字(タイトルロゴ、オープニング動画など)。
- ゲームの更新で新しく追加された文言(翻訳が追加されるまで、英語のまま表示されます)。

## 注意事項

- **ゲームの更新**: ゲームが更新されると、一部の機能が動かなくなったり、新しい文言が英語のまま表示されたりすることがあります。
  その場合も、ゲーム自体は英語などの元の表示で遊べます。
- **他のMODとの併用**: 既に BepInEx 5 を導入している場合は、日本語化プラグインだけを追加し、元の BepInEx には手を加えません。
  「元に戻す」でも、日本語化プラグインだけを取り除きます。BepInEx 6 や、`winhttp.dll` を使う別のMODローダーとは併用できません。
- **翻訳の内容**: 医療に関する説明はゲームの雰囲気づくりのためのもので、医学的な正確さを保証するものではありません。
  実際の病気や治療については、医療機関や公的な情報源を参照してください。
- **翻訳の作成方法**: 翻訳は AI(Claude)を用いて作成し、用語の統一と機械的な検証を行っています。
  誤訳や不自然な表現が残っている可能性があります。修正の提案を歓迎します。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 「インストールされていません」と表示される | Steam 版がインストール済みか確認してください。Steam 以外の版には対応していません。 |
| 「起動中です」と表示される | ゲームを終了してから、もう一度実行してください。 |
| 日本語にならない | ゲームの「オプション」画面で「日本語」が選ばれているか確認し、ゲームを再起動してください。 |
| 文字が□になる・表示が崩れる | 「元に戻す」→「日本語化する」をやり直してください。改善しない場合は、ゲームフォルダの `BepInEx\LogOutput.log` を添えて報告してください。 |

Steam の「ゲームファイルの整合性を確認」を実行しても、このパッチが追加したファイルは削除されません。
取り除くには「元に戻す」を使ってください。

## 手動で導入する場合

EXE を使わずに導入することもできます。

1. ZIP 内の `payload` フォルダの**中身**を、ゲームのフォルダ(`BioIncRedemption.exe` がある場所)へコピーします。
2. 取り除くときは、コピーしたファイル(`BepInEx` フォルダ、`winhttp.dll`、`doorstop_config.ini`、`.doorstop_version`、`changelog.txt`)を削除します。
   手動で導入した場合でも、`BioIncRedemptionJP.exe` の「元に戻す」で取り除けます。

## コマンドラインからの操作

画面を出さずに操作することもできます。

```text
BioIncRedemptionJP.exe --status     状態を表示
BioIncRedemptionJP.exe --apply      日本語化する
BioIncRedemptionJP.exe --revert     元に戻す
  --game-dir <フォルダ>   ゲームのフォルダを直接指定する
  --log <ファイル>        結果をファイルへ書き出す
```

## 仕組み

- MODローダー [BepInEx](https://github.com/BepInEx/BepInEx) を使い、ゲームの起動時に日本語化プラグインを読み込みます。
- プラグインは、ゲームが言語データを読み込んだ直後に、日本語訳(`ja.xml`)をメモリ上で重ねます。訳の無い文言は元の言語のまま残ります。
- 日本語の文字は、同梱の Noto Sans JP から実行時にフォントを作り、ゲームのフォントの代替として登録して表示します。
- パッチツールは、何を追加したかをゲームフォルダの `BioIncRedemptionJP_PatchData` に記録し、「元に戻す」ではその記録に従って取り除きます。

設定ファイルは、ゲームを一度起動するとゲームフォルダの `BepInEx\config\io.github.utausnskareshi.bioincredemptionjp.cfg` に作られます
(フォントの差し替えなどができます)。

## 翻訳の修正に協力する

翻訳は [translation/ja.xml](translation/ja.xml) にあります。形式はゲーム本体の言語ファイルと同じです。

```xml
<string name="Button.Close">閉じる</string>
```

- 文体や記号の決まりは [スタイルガイド](translation/STYLE_GUIDE.md)、訳語の一覧は [用語集](translation/GLOSSARY.md) にまとめています。
- `{0}` などの書式指定子、`<b>` などのタグ、`[arg]` などの記号は、原文と同じ数だけ残してください。
- ゲームフォルダの `BepInEx\plugins\BioIncRedemptionJP\ja.xml` を書き換えて試せます。
  ゲーム中に `Ctrl + F10` で翻訳を読み込み直し、`Ctrl + F9` で各文言のキーを表示できます。

## ビルド方法

必要なもの: Windows、.NET SDK 10、Steam 版 Bio Inc. Redemption(プラグインのビルドにゲーム本体のDLLへの参照が必要です)。

```powershell
.\build\build.ps1
```

`dist` フォルダに配布用ZIPが作られます。ゲームの場所は Steam から自動で検出します。

| フォルダ | 内容 |
|---|---|
| `src/BioIncJp.Plugin` | 日本語化プラグイン(BepInEx 5 用) |
| `src/BioIncJp.Localization` | 翻訳ファイルの読み込み・検証(ゲームに依存しない部分) |
| `src/BioIncJp.Patcher` | パッチツールの画面(WPF) |
| `src/BioIncJp.Patcher.Core` | パッチツールの中核(Steam の検出、適用、復元) |
| `translation` | 日本語訳、スタイルガイド、用語集 |
